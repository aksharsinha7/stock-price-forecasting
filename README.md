# Stock Price Forecasting

This project uses machine learning to predict stock price movement using historical market data.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Features
- Data preprocessing
- Feature engineering
- Model training
- Visualization

## Goal
Build a model capable of predicting short-term stock price trends with low prediction error.
